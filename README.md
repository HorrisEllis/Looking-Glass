# Looking Glass

A UI renderer, app host, UI editor and app builder — written in Emerge, to replace Electron and build applications from Emerge code.

Read in this order:
1. `SPEC.md` — what it is and why (v0.3, kept as written)
2. `PHASEMAP.md` — the phased build plan with exit tests (kept as written)
3. `ADDENDUM-2026-11-15.md` — what has been decided since: all Emerge, Emerge first, the editor and builder, Electron import
4. `docs/eravos-v2-emerge-looking-glass.md` — the road from today's Emerge to Looking Glass, and ERAVOS on it

Nothing is built yet. The first build step is LG1: one borderless window that draws one rectangle from data.
